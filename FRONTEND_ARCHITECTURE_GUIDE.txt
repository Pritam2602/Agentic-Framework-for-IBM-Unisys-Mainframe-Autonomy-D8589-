API FLOW DIAGRAM
================

User enters query: "Show me payroll for March 2026"
  
handleSendMessage()
  
Step 1: extractIntent(query)
  - Make POST to /api/intent/extract
  - Receive IntentResponse
  - Update state: intent.status = 'completed', intent.data = response
  - IntentPanel displays result
  
Step 2: resolveContext(intent)
  - Make POST to /api/context/resolve (not yet implemented)
  - Receive Context data (IBM programs/datasets, Unisys APIs)
  - Update state: context.status = 'completed', context.data = response
  - ContextPanel displays result
  
Step 3: createPlan(intent, context)
  - Make POST to /api/planner/plan (not yet implemented)
  - Receive PlanData with execution steps
  - Update state: planner.status = 'completed', planner.data = response
  - PlannerPanel displays steps
  
Step 4: executeSteps(plan)
  - Make POST to /api/agent/execute
  - Receive execution results
  - Update state: execution.status = 'completed', execution.data = response
  - ExecutionResultPanel displays results

IMPLEMENTATION EXAMPLE
=====================

// In ExecutionPage.tsx

import { useState } from 'react';
import { 
  PipelineVisualization, 
  IntentPanel, 
  ContextPanel, 
  PlannerPanel, 
  ExecutionResultPanel,
  type PipelineState 
} from '../components/pipeline';
import { extractIntent } from '../services/agentPipeline';

export default function ExecutionPage() {
  const [pipelineState, setPipelineState] = useState<PipelineState>({
    userQuery: '',
    stages: {
      intent: { id: 'intent', name: 'Intent', status: 'pending' },
      context: { id: 'context', name: 'Context', status: 'pending' },
      planner: { id: 'planner', name: 'Planner', status: 'pending' },
      execution: { id: 'execution', name: 'Execution', status: 'pending' }
    }
  });

  const handleSendMessage = async (query: string) => {
    setPipelineState(prev => ({
      ...prev,
      userQuery: query,
      stages: {
        intent: { ...prev.stages.intent, status: 'processing' },
        context: { ...prev.stages.context, status: 'pending' },
        planner: { ...prev.stages.planner, status: 'pending' },
        execution: { ...prev.stages.execution, status: 'pending' }
      }
    }));

    try {
      // Step 1: Extract Intent
      const startTime = Date.now();
      const intent = await extractIntent(query);
      const duration = Date.now() - startTime;

      setPipelineState(prev => ({
        ...prev,
        stages: {
          ...prev.stages,
          intent: {
            ...prev.stages.intent,
            status: 'completed',
            data: intent,
            duration
          },
          context: { ...prev.stages.context, status: 'processing' }
        }
      }));

      // Step 2: Resolve Context (future implementation)
      // ...

      // Step 3: Create Plan (future implementation)
      // ...

      // Step 4: Execute (future implementation)
      // ...

    } catch (error) {
      setPipelineState(prev => ({
        ...prev,
        stages: {
          ...prev.stages,
          intent: {
            ...prev.stages.intent,
            status: 'error',
            error: error.message
          }
        }
      }));
    }
  };

  return (
    <Layout>
      <div className="space-y-4">
        {/* Main Pipeline Visualization */}
        <PipelineVisualization pipeline={pipelineState} />

        {/* Detailed Stage Panels (Collapsible) */}
        <div className="grid grid-cols-1 lg:grid-cols-2 gap-4">
          <IntentPanel 
            intent={pipelineState.stages.intent.data}
            loading={pipelineState.stages.intent.status === 'processing'}
          />
          
          <ContextPanel 
            context={pipelineState.stages.context.data}
            loading={pipelineState.stages.context.status === 'processing'}
          />

          <PlannerPanel 
            plan={pipelineState.stages.planner.data}
            loading={pipelineState.stages.planner.status === 'processing'}
          />

          <ExecutionResultPanel 
            result={pipelineState.stages.execution.data}
            loading={pipelineState.stages.execution.status === 'processing'}
          />
        </div>

        {/* Input Section */}
        <div className="flex gap-2">
          <textarea 
            value={inputText}
            onChange={(e) => setInputText(e.target.value)}
            placeholder="Enter your query..."
            className="flex-1 p-2 rounded bg-slate-800 text-white"
          />
          <button
            onClick={() => handleSendMessage(inputText)}
            className="px-4 py-2 bg-cyan-600 rounded hover:bg-cyan-700"
          >
            Execute
          </button>
        </div>
      </div>
    </Layout>
  );
}

UI FEATURES
===========

1. PIPELINE VISUALIZATION
   - Shows all 4 stages: Intent  Context  Planner  Execution
   - Each stage has status indicator:
     * Pending (gray circle)
     * Processing (animated clock)
     * Completed (green checkmark)
     * Error (red circle)
   - Click stage to expand and see data
   - Duration shown for completed stages

2. INTENT PANEL
   - Task type (fetch, compare, analyze, etc.)
   - Entities (payroll, customer, transaction)
   - Attributes (employeeId, netSalary, etc.)
   - Systems (IBM, Unisys)
   - Priority level
   - Confidence score with progress bar
   - JSON display for debugging

3. CONTEXT PANEL
   - IBM z/OS sources
     * Programs (COBOL programs)
     * Datasets (file names)
     * Jobs (JCL jobs)
   - Unisys ePortal sources
     * APIs (/api/unisys/payroll)
     * Endpoints
     * Services
   - Left border color indicates system

4. PLANNER PANEL
   - Numbered execution steps
   - System badge for each step (IBM/Unisys)
   - Action description
   - Command or API call
   - Parameters object
   - Estimated total duration

5. EXECUTION RESULT PANEL
   - Status: Success/Error/Pending
   - Source tagging (Which system provided data)
   - Duration in ms
   - Records found
   - Data output with syntax highlighting
   - Error messages if failed
   - Timestamp
