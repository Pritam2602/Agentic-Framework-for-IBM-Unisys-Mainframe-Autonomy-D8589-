STATE FLOW
==========

1. User enters query
2. handleSendMessage() called
3. Stage 1: Intent Agent
   - Call extractIntent(query)
   - Update state: intent.status = 'processing'
   - Receive IntentResponse
   - Update state: intent.status = 'completed', intent.data = response
   - IntentPanel renders automatically
4. Stage 2: Context Resolution
   - Call getContext(intent)
   - Show resolved sources
   - ContextPanel renders
5. Stage 3: Planner
   - Call getPlan(context)
   - Show execution steps
   - PlannerPanel renders
6. Stage 4: Execution
   - Call executeSteps(plan)
   - Show final results
   - ExecutionResultPanel renders

All stages shown simultaneously in PipelineVisualization

API INTEGRATION
===============

POST /api/intent/extract
  Input:  { user_query: string, enable_llm?: boolean }
  Output: IntentResponse (from IntentPanel.tsx)
  Service: extractIntent()

POST /api/agent/execute
  Input:  { query: string }
  Output: Full execution result
  Service: executeAgentPipeline()

GET /api/agent/reasoning-stream
  Output: Server-Sent Events with reasoning logs
  Service: streamReasoningLogs()

COMPONENTS CAN BE USED INDEPENDENTLY
====================================

Each panel is self-contained and can be used separately:

<IntentPanel intent={intentData} loading={false} />
  - Displays just the intent extraction
  - Can be embedded in other pages

<ContextPanel context={contextData} loading={false} />
  - Shows data sources independently
  - Useful for debugging

<PlannerPanel plan={planData} loading={false} />
  - Displays execution plan
  - Can be previewed before execution

<ExecutionResultPanel result={resultData} loading={false} />
  - Shows only the final result
  - Can display historical results

<PipelineVisualization pipeline={pipelineState} />
  - Shows all stages in flow
  - Primary dashboard view
